# Hostel Website

A four-page responsive website for OC19 LOUNGE in Dakar, Senegal. It uses HTML, CSS, and plain JavaScript, with no framework or backend.

## Files

- `index.html` — home page and hostel highlights.
- `rooms.html` — room examples and rates.
- `about.html` — introduction and contact details.
- `booking.html` — demo inquiry form.
- `styles.css` — colors, layout, and mobile styles.
- `script.js` — checks that departure is after arrival.
- `images/` — example photos used by the pages.

## Open the site

Open `index.html` in a browser. No installation is needed.

## What to show

1. Use the navigation to visit Home, Rooms, About & Contact, and Booking.
2. On Rooms, show the shared-room price of 75,000 FCFA per person per night and the private-room price of 100,000 FCFA per room per night.
3. On Booking, try an empty form, then enter a departure date before arrival to show validation.
4. Submit valid sample details to display the demo message.

## How it works

HTML provides the page content and form labels. CSS sets the green and cream colors, card layouts, and responsive styles. JavaScript checks the travel dates and shows a message when the form is submitted.

The form is a demonstration only. It does not send an inquiry, save information, check availability, or confirm a booking.

## Details to confirm before publishing

- The pool and room photos are examples, not verified hostel photos.
- Private-room features are suggestions; bathroom privacy, capacity, taxes, and included cafeteria or activities should be confirmed.
